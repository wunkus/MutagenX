**MutagenX** is a top-down roguelike, survivor-style game I am developing for a college project.

The player uses a combination of different mutations, which give the player different abilities and powers. Their attacks are activated automatically, similar to games of the Survivor genre.

The game's goal is to use the mutations to defeat enemies, where after a certain number are defeated, another drop pod arrives, where the player can escape the planet.
